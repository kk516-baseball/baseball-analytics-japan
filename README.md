# Baseball Analytics Japan

数字でプロ野球をもっと楽しむ ― NPB(日本プロ野球)のスタッツを軸に選手・チームを掘り下げる、ブラウザだけで動くデータサイトです。

🔗 公開URL: （GitHub Pagesを有効化したらここにURLを記載）

## 機能

- **選手検索** ― 名前・チーム・ポジション・年度・出身校・ドラフト順位・年俸で絞り込み
- **成績一覧** ― 野手/投手別の全項目ソート可能テーブル
- **年度別ランキング** ― 安打・本塁打・OPS・防御率・WHIPなどのTOP10
- **チーム比較** ― 得点・失点・OPS・防御率・守備率を並べて比較
- **選手比較** ― 任意の2選手を横並びで比較
- **対戦成績** ― 打者×投手の通算対戦成績
- 選手詳細モーダル ― 年度比較・月別成績・球場成績・二軍成績

## データについて

- **選手の基本情報**（背番号・氏名・生年月日・身長体重・投打・ポジション）は、NPB公式サイト(npb.jp)のチーム別選手一覧に基づく実データで、12球団の支配下選手全員（800名超）を収録しています。
- **選手検索・成績一覧・ランキング・選手比較・年度比較**の詳細シーズンスタッツ（打率・防御率など）は、NPB公式サイト(npb.jp)の個人成績表に基づく実データ（2022〜2024年）ですが、実在選手50名分のみの収録です。対象外の選手は基本情報のみの表示になります（選手検索の「詳細スタッツ」フィルタで絞り込めます）。
- 得点圏打率・被打率・QS率はNPBが公表していないため「---」表示です。
- 規定打席・規定投球回に到達しなかったシーズンは「データなし」として表示されます。
- **対戦成績・球場成績・月別成績・二軍成績**は公式集計が存在しないため、実際のシーズン成績を基にしたシミュレーション値です。
- 年俸はすべて報道による推定値です。

## 技術構成

- `index.html`（骨格）／`style.css`（デザイン）／`players.js`（選手データ）／`app.js`（検索・ランキング・比較などのロジック）に分割
- 外部ライブラリ・ビルドツール不要。`index.html`をブラウザで直接開くだけで動作します（`<script src>`形式のためローカルのfile://でもCORSの影響を受けません）
- レスポンシブデザイン対応（スマートフォン〜デスクトップ）

## データソース（data/）

`data/`にはnpb.jpから取得したロースターCSVを収録しています。`npb_roster_all12.csv`が12球団統合済みのマスターデータ、`npb_roster_batch1〜3_*.csv`は取得時のチーム別内訳です。
